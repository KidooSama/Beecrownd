# Beecrowd Exercises

Repositório dedicado às minhas resoluções de problemas da plataforma Beecrowd utilizando PHP 8.1.

O objetivo deste repositório é praticar lógica de programação, algoritmos, manipulação de dados e reforçar fundamentos importantes da linguagem através de desafios variados.

## Tecnologias

- PHP 8.1(Python e C++ nos casos antigos)
- Git
- VSCode

## Estrutura

Os exercícios são organizados por arquivos `.php`, contendo a solução de cada problema proposto pela plataforma.

## Plataforma

Os desafios utilizados podem ser encontrados em:

https://judge.beecrowd.com/pt/categories

## Objetivo

Além de praticar programação competitiva, este repositório também serve como forma de evolução pessoal e reforço dos conceitos fundamentais utilizados no desenvolvimento backend.
